# 完整备份分卷（不含六份原版 PDF）

本备份来自 D:\\switchgear-quote-full-backup，包含 1,154 个文件，保留原目录结构；已排除 source_books/ 下六份原版 PDF。技能最新的本机 CAD/PDF 检查以仓库 switchgear-quote/ 目录为准，备份反映本机备份文件夹的内容。

28 个分卷按编号连接后得到 ZIP，大小 137552061 字节；SHA-256 为 89223D7DB840F55AB7AFE5CDD52A109D48156CDEC2160AA2330C2E5352BF4EE4。

在 Windows PowerShell 中，先把“分卷”目录完整下载到本机，进入其父目录后执行：

```powershell
$parts = Get-ChildItem -LiteralPath '.\分卷' -Filter 'backup.zip.part*' | Sort-Object Name
if ($parts.Count -ne 28) { throw '分卷不完整，应有 28 个' }
$out = [IO.File]::Create((Join-Path (Get-Location) '完整备份.zip'))
try { foreach ($p in $parts) { $inputStream = [IO.File]::OpenRead($p.FullName); try { $inputStream.CopyTo($out) } finally { $inputStream.Dispose() } } } finally { $out.Dispose() }
Get-FileHash -Algorithm SHA256 '.\完整备份.zip'
```

核对 SHA-256 一致后，再用系统解压工具解压。该仓库为公开仓库。
