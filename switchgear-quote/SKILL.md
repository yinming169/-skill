# 高低压柜报价文件整理

把图纸变成可报价的 Excel 材料清单。核心链路：**图纸 → 结构化提取 → 型号/尺寸归一化 → 价格库匹配 → 分项报价单**。

## 何时用这个 skill

- 用户给出 DWG / DXF / PDF 图纸，要求出材料清单或报价单
- 用户要求统计柜内元器件型号数量、柜体尺寸、铜排用量
- 用户要求把已有报价单核对/重构/补价

## 铁律（先读，别跳）

1. **绝不编造型号**。图纸上没写的型号一律留空并在 `待确认` 列标记 `缺型号`，不许按"经验"补一个看起来合理的。
2. **绝不编造价格**。价格只能来自 `price_db`（用户历史报价/采购价）。未匹配到的单价留空、整行标黄，输出到 `未匹配清单`。
3. **提取结果必须给人过目**。`extract.json` 和 `识别核对表` 是给人复核用的中间产物，不要跳过直接出报价单。
4. **铜排和柜体尺寸是推算值**，不是提取值。输出时必须带 `推算依据` 说明，并在表头标注"待复核"。

## 标准工作流

```
第0步  收集输入：图纸文件 + 价格库(price_db.xlsx) + 报价模板(可选)
第1步  分流     python scripts/dispatch.py <图纸目录或文件> --out work/
第2步  提取     python scripts/extract.py work/manifest.json --out work/extract.json
第3步  识别     python scripts/classify.py work/extract.json --out work/items.json
第4步  核价     python scripts/price_match.py work/items.json --db price_db.xlsx --out work/priced.json
第5步  出单     python scripts/build_quote.py work/priced.json --out 报价单.xlsx
```

`scripts/pipeline.py` 是一键串起 1-5 步的封装：

```bash
python scripts/pipeline.py --input <图纸或目录> --db price_db.xlsx --out 报价单.xlsx
```

## 三种图纸链路（自动分流）

| 类型 | 判定 | 提取器 | 准确率 | 说明 |
|---|---|---|---|---|
| DWG/DXF | 扩展名 | `extract_dxf` | 高 | 读 INSERT 块名+ATTRIB、TEXT/MTEXT、图层。**最可靠** |
| PDF 矢量 | PDF 内文字可选中 | `extract_pdf` | 中高 | PyMuPDF 抽文字+坐标，pdfplumber 抽表格 |
| PDF 扫描/图片 | 页面无文字层 | `extract_ocr` | 中 | 需 PaddleOCR，逐页 OCR，必须人工复核 |

DWG 无法用 Python 直接解析。请自行安装 LibreDWG 并将 dwg2dxf 加入 PATH，然后转换：

```bash

dwg2dxf -o out.dxf in.dwg
```

AC1021(2007)/AC1032(2018) 实测可转，14MB DXF 约 2.5 秒解析完。转换时会刷 `Warning: Unstable Class object`，属正常，不影响文字提取。
备选：用户用 CAD 另存 DXF，或装 ODA File Converter。**不要尝试直接读 DWG 二进制**——R2007 以后数据段压缩，扫出来的全是乱码。

## 识别什么

### 识别优先级（重要，按此顺序）

**① 首选：电气原理图图块识别**

电气原理图/系统图上，每个元器件是一个图块（DXF INSERT）。这是最可靠的来源：

- **数量 = 图块引用次数**（一个符号就是一个元器件，不会说谎）
- **型号 = 就近匹配文字标注**（默认 900 图纸单位半径内最近的含型号文字）
- **只处理电气图层**：图层名含「系统」「原理」「控制」「电气」
- **排除平面图图层**：含「平面」「导线」「照明平面」「图框」「轴线」「COLUMN」「AXIS」「BXT」「文字」「DIM」

实测（压滤机房 DWG）：电气图层 61 个图块 → 匹配 30 个 → 10 种物料，数量全对。

**② 补充：图纸中的材料表**

图纸的「电气设备材料表」通常只到**柜级**（柜型、台数、尺寸），不含柜内元器件明细。
用途：补柜体、柜型、柜体尺寸，**不用于统计柜内元器件数量**。

**③ 兜底：全图文字扫描**

仅在图块识别无结果时启用（如纯 PDF 矢量图无图块）。数量靠启发式推断，置信度标 `low`，必须人工核对。

### 型号写法规范（重要）

材料清单里的型号**只写通用代号 + 规格参数，不写厂家系列**——实际订货可能换牌，型号里带厂家系列会锁死供应商。

| 类别 | 统一写法 | 转换示例（含 M/L/H 剥离） |
|---|---|---|
| 微型断路器 | `MCB-…` | `iC65N-C20A/2P` → `MCB-C20A/2P`；`DZ47-63 C16 2P` → `MCB-63 C16 2P`；`NXB-63 C16` → `MCB-63 C16` |
| 塑壳断路器 | `MCCB-…` | `CM3-250M/3300` → `MCCB-250/3300`；`NSX100N TM100 3P` → `MCCB-100N TM100 3P`；`CM5-250L/33002` → `MCCB-250/33002` |
| 框架断路器 | `ACB-…` | `CW3-1600/3` → `ACB-1600/3`；`E2N 2000` → `ACB-2000` |

**壳架电流后的分断等级字母 M/L/H 不写进型号**——那是厂家分断等级代号，订货换牌会变。改用「极限分断能力 Icu」字段统一注明，每张清单按此标注，避免等级写错或漏项：

| 断路器类别 | 极限分断能力 Icu | 判定依据 |
|---|---|---|
| 微型断路器 MCB | `10kA` | 固定 |
| 塑壳断路器 MCCB | `>50kA` | 固定（塑壳选高分断） |
| 框架断路器 ACB ≤2500A | `65kA` | 按额定电流，如 ACB-1600 |
| 框架断路器 ACB >2500A | `85kA` | 按额定电流，如 ACB-3200 |

**规格参数仍须保留**：壳架电流、脱扣器型号、极数、脱扣曲线。只去掉厂家系列名 + M/L/H 分断等级字母，分断能力改由 Icu 字段注明。

实现用**系列映射表**（`to_generic_model`）：先把厂家系列换成通用代号并剥掉 M/L/H，再用 `breaking_capacity()` 按上表算出 Icu 写进 `breaking_capacity` 字段。不能用正则替换——正则会吃掉壳架数字，`NSX100N` 会被替换成 `MCCB`，把关键的 `100N` 丢了。

品牌信息记在「品牌」列，不写进型号。

### 型号库覆盖

`references/recognition-rules.md` 收录：微断、塑壳、框架、接触器、热继、双电源、互感器、仪表、浪涌、隔离、熔断器、电容、软启、变频。

**注意图纸常用通用代号而非品牌系列**，型号库必须同时支持：
- `MCB`（微型断路器通用）、`MCCB`（塑壳通用）、`ACB`（框架通用）
- `CM3`/`CM5`（常熟塑壳）、`CW3`（常熟框架）
- `AF`/`A`（ABB 接触器）、`ACR`（安科瑞仪表）

漏了这些通用代号，图块识别会全部落空——这是踩过的坑。

**选型理论依据**见 `references/electrical-knowledge.md`（整理自《常用低压供配电设备选型与安装技术手册》《电气控制工程师手册》）：断路器/接触器/热继/熔断器/互感器/铜排的选型计算式、使用类别 AC-1~AC-4 的适用场合、国产↔进口型号对照表、影响报价的安装工艺要求。报价遇到"该配多大"的疑问先查这份。

## 报价单结构（Excel 输出）

固定 6 个 sheet，顺序不要改：

1. `封面` — 项目名、柜号清单、报价日期、版本
2. `元器件清单` — 按柜号分组的元器件分项，列：柜号/序号/类别/名称/型号/品牌/单位/数量/单价/加价率/售价/小计/来源/备注
3. `柜体部件` — 柜架、门板、隔板、母线框、绝缘子、风机、照明、辅材
4. `铜排清单` — 规格/单重/长度/重量/单价/金额/推算依据
5. `汇总` — 分类成本、加价后金额、利润率、税金、总价
6. `未匹配清单` — 价格库没命中的行，标黄，供人工补价

## 配套件规则（按设备自动配附件）

配置在 `references/accessory_rules.json`。当前规则：

| 触发设备 | 每个配 |
|---|---|
| 马达保护器 | 中间继电器 ×4 + 熔断器 ×4 |
| 接触器 | 指示灯 ×2 + 三开两闭（3NO+2NC）辅助触点 ×1 |
| 开关（断路器/隔离开关） | 指示灯 ×1 |
| 变频器 | 信号放大器 ×1 + 中间继电器 ×4，且规格须含 2路模拟量输入+2路模拟量输出 |

执行方式：与原表已有数量比对，**只补差额，不重复计算**。原表已有该行就改数量（红色加粗标记），没有才新增行，新增行紧跟触发设备插入。

`options.exclude_mcb_from_switch`：设为 `true` 时「每个开关配1个指示灯」不把微型断路器算作开关。柜内微断数量多，按字面执行会配出大量指示灯，按需切换。

## 按用户模板出表

用户既有清单格式固定为「分项报价表」，单 sheet `分项明细`：

```
第1行  标题（A:H 合并）
第2行  项目名称（A:H 合并，下边框）
每柜三件套：
  柜头行  A:C合并=柜名 | D=台 | E=柜数 | F:G合并="以下为单台配置"
  表头行  序号|名     称|规格型号|单位|数量|单价|金额
  明细行  G列公式 =IF($F{n}="","",$E{n}*$F{n})
  小计行  B:D合并=单台材料小计 | E=柜数 | G=IF(COUNT(G起:G止)=0,"",SUM(...))
  空一行
```

样式：宋体 10.5，全细边框，名称/规格左对齐其余居中，全部自动换行。
列宽 A5.3 B17.375 C34.8 D5.3 E6 F6.9 G7.7 H10.7。
行高 标题30 / 项目22 / 柜头28 / 表头26 / 明细28 / 小计35。

生成命令：

```bash
python scripts/template_quote.py <源清单.xlsx> --out <配齐版.xlsx>
```

输出两个 sheet：`分项明细`（原格式 + 配齐）和 `配套核对表`（每柜：规则应配 / 原表已有 / 本次补齐 / 触发规则），供人工核对。

## 加价与利润

逐项加价，按类别设不同加价率，配置在 `references/markup_rates.json`。默认（可改）：

| 类别 | 默认加价率 |
|---|---|
| 断路器/开关类 | 8% |
| 接触器/继电器 | 10% |
| 仪表/互感器 | 12% |
| 柜体/钣金 | 25% |
| 铜排 | 15% |
| 辅材 | 20% |

售价 = 单价 × (1 + 加价率)。汇总 sheet 单独算综合毛利率，方便核对是否达标。

## 价格库格式

`assets/price_db_template.xlsx` 是空白模板（含填写说明），复制一份填自己的历史价即可。

| 物料编码 | 类别 | 名称 | 型号 | 品牌 | 单位 | 单价 | 供应商 | 更新日期 | 备注 |
|---|---|---|---|---|---|---|---|---|---|

匹配策略：型号归一化（大写、去空格、统一 `×`/`*`/`x`、去多余连字符）后精确匹配 → 包含匹配 → 模糊匹配（相似度 ≥0.86）→ 名称+品牌。
柜体部件按**名称**匹配（型号列常是尺寸，不可靠）。铜排只匹配单位为 kg 的行，避免串到按米计价的辅材。

## 常见坑

- **同型号不同附件**：`NSX100N TM100 3P` 和 `NSX100N TM100 3P + 电操` 是两个价，别合并
- **数量单位**：图纸写"3P"是极数不是数量；"1用1备"是 2 台
- **柜体尺寸顺序**：国内习惯 `宽×高×深`，欧洲图纸可能是 `W×D×H`，看标题栏单位说明
- **铜排规格写法**：`TMY-80×10`、`TMY 80*10`、`80x10铜排`、`-80×10` 都要认
- **扫描件方向**：OCR 前先判旋转，横排图纸经常是旋转 90° 存的
