# 统一入口

运行 `python scripts/unified.py --status` 检查当前 Python 的依赖及电脑上可发现的 FreeCAD、GElectrical。使用 `python scripts/unified.py --input 图纸路径` 检查分流；出报价单时再加 `--db 价格库.xlsx --out 报价单.xlsx`。DWG 当前必须先转成 DXF；扫描 PDF 需 OCR，失败会停止出表。缺少依赖时明确提示。

本入口复用现有提取、识别及标准表生成脚本。FreeCAD 和 GElectrical 目前只检测程序是否可找到，尚无自动调用接口；外部符号识别模型尚未安装或接入。检测到程序不等于已验证其兼容性。所有识图结果须逐页逐柜复核；保持标准材料表格式和备注列规则。
