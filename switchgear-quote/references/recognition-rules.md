## 二、元器件型号前缀 → 类别 / 品牌

### ⚠ 先看这条：图纸常用「通用代号」而非品牌系列

实际图纸（尤其设计院出的订货图）大量使用通用代号，型号库里**必须同时支持**，否则图块识别会全部落空：

| 通用代号 | 含义 | 图纸实例 |
|---|---|---|
| `MCB` | 微型断路器 | MCB-C16A/1P、MCB-63A/3P |
| `MCCB` | 塑壳断路器 | MCCB-63M/3300、MCCB-400M/3300 |
| `ACB` | 框架（空气）断路器 | ACB-2000/3 |
| `CM3` / `CM5` | 常熟塑壳 | CM3-250M/3300、CM5-250L/33002 |
| `CW3` | 常熟框架 | CW3-1600/3、CW3-2500A/3P |
| `AF` / `A` | ABB 接触器 | AF190-30-11、A110 |
| `ACR` | 安科瑞仪表 | ACR220EL |

**坑**：`MCB` 与 `MCCB` 前缀重叠，正则必须写 `MCB(?!C)`，否则 `MCCB` 会被切成 `MCB` + `CB`。

**规范化阶段的 M/L/H**：上表中塑壳图纸常带分断等级字母（`CM3-250M`、`MCCB-63M`），这些是厂家分断等级代号，**不进最终型号**。在 `to_generic_model` 里剥掉（`250M/3300`→`250/3300`），分断能力改由 `breaking_capacity()` 按规则算成 Icu 字段（MCB=10kA、MCCB=>50kA、ACB 按额定电流 ≤2500A→65kA / >2500A→85kA）。B/C/D 曲线字母、N/S 等级不动。

### 微型断路器（MCB）
| 前缀 | 品牌 | 示例 |
|---|---|---|
| iC65N/H/L、C65、EA9 | 施耐德 | iC65N-C20A/2P |
| SH200、S200、GSH200 | ABB | SH203-C16 |
| 5SJ、5SY | 西门子 | 5SJ6216-7CC |
| DZ47、NXB、CDB | 正泰/德力西 | DZ47-63 C16 2P |
| iDPN（漏电） | 施耐德 | iDPN N Vigi 20A |

**读法**：`iC65N - C 20A / 2P` = 系列-脱扣曲线-额定电流/极数。报价必须带全，少一个参数价差 3 倍。

### 塑壳断路器（MCCB）
| 前缀 | 品牌 |
|---|---|
| NSX、NSE、EZD、CVS | 施耐德 |

## 三、柜体尺寸解析

支持的写法：
```
800×2200×600          国内惯例 宽×高×深
800*2200*600          星号
800x2200x600          小写x
W800×H2200×D600       带标签，最可靠
(宽800 高2200 深600)   中文标签
```

**判定逻辑**：带 W/H/D 标签的优先按标签取；否则默认 `宽×高×深`，若第二个数不是最大值则按 `宽×深×高` 重排（高度通常是最大尺寸）。

**常见规格参考**：
- 低压抽屉柜：宽 600/800，高 2200，深 800/1000
- 低压固定柜 GGD：宽 800/1000，高 2200，深 600
- 高压中置柜 KYN28：宽 800，高 2300，深 1500
- 环网柜：宽 375/750，高 1600，深 940
- 配电箱 PZ30：宽 300-800，高 400-1200，深 150-250

## 四、铜排用量推算

### 规格选型（按主母排额定电流）
| 电流 | 规格 | 截面积 mm² |
|---|---|---|
| ≤250A | TMY-30×4 | 120 |
| ≤400A | TMY-40×5 | 200 |
| ≤630A | TMY-50×6 | 300 |
| ≤800A | TMY-60×8 | 480 |
| ≤1000A | TMY-80×10 | 800 |
| ≤1250A | TMY-100×10 | 1000 |
| ≤1600A | TMY-120×10 | 1200 |
| ≤2000A | TMY-2×(100×10) | 2000 |
| ≤2500A | TMY-2×(120×10) | 2400 |
| ≤3200A | TMY-3×(100×10) | 3000 |

### 长度计算
```
主母排长度 = (柜宽 mm + 300mm 搭接余量) / 1000 × 5 根 × 柜数
             5 根 = 3 相 + N + PE（TN-S 系统）
分支排长度 ≈ 开关回路数 × 0.8m（粗估，需按实际排布复核）
```

### 重量计算
```
kg = 8.9 (铜密度 g/cm³) × 长度(m) × 截面积(mm²) / 1000 × 股数
```
校验：TMY-80×10 单根约 **7.12 kg/m**。

### 注意事项
- 双排/三排写法 `2×(100×10)` 要乘股数
- 铜排按 **kg** 计价，不是按米，价格库单位必须是 kg
- 高压柜母排通常按相分室布置，长度要按柜深另算，本规则偏保守
- 铜价波动大，报价前务必更新价格库

## 五、加价率（逐项加价）

配置在 `references/markup_rates.json`。默认值：

| 类别 | 加价率 | 理由 |
|---|---|---|
| 断路器/开关 | 8% | 品牌透明，客户会查价 |
| 接触器/继电器 | 10% | |
| 仪表/互感器 | 12% | |
| 柜体/钣金 | 25% | 自制件，议价空间大 |
| 铜排 | 15% | 跟随铜价 |
| 辅材 | 20% | 零碎项，按项计 |

售价 = 成本单价 × (1 + 加价率)。汇总表另算综合毛利率，用于判断是否达到投标要求。

## 六、常见坑

1. **极数不是数量**：图纸写 "3P" 是极数，"1用1备" 才是 2 台。
2. **同型号不同附件**：`NSX100N TM100 3P` 与 `+电操`、`+分励` 是两个价。
3. **柜体尺寸顺序**：欧洲图纸可能是 W×D×H，看标题栏单位说明。
4. **铜排写法**：`TMY-80×10`、`TMY 80*10`、`80x10铜排`、`-80×10` 都要认。
5. **扫描件方向**：横排图纸常旋转 90° 存储，OCR 前先判方向。
6. **一张图纸多柜**：系统图可能一页画 5 个柜，柜号在每段上方，需要按柜号分段统计。
7. **备用回路**：图纸标"备用"的回路通常只留空开位置，不含断路器，报价前确认。
