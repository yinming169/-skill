## 二、检索（最常用）

### 方式1：直接读知识卡片（最快，推荐）

报价遇到常见问题，先读 `cards/` 下的结构化卡片：

| 问题 | 读哪张卡片 |
|---|---|
| 铜排该选多大？载流量多少？ | `cards/card-01-主母线铜排载流量.md` |
| 断路器怎么选？Icu/Ics/Icw 什么意思？ | `cards/card-02-断路器选型要点.md` |
| 接触器 AC-3/AC-4 有什么区别？ | `cards/card-03-接触器与起动器选型.md` |
| 上下级怎么配合才不越级跳闸？ | `cards/card-04-级间选择性.md` |
| 这个电流配什么型号断路器？ | `cards/card-05-常用断路器参数速查.md` |

### 方式2：全文检索（查原始出处）

```bash
cd knowledge

# 单词检索
python tools/search.py 分断能力

# 多词 = AND
python tools/search.py 断路器 选择性

# 限定书目、加大上下文
python tools/search.py 铜排 载流量 --book 资料4 --ctx 3 --max 10

# 整串精确匹配
python tools/search.py "低压成套开关设备" --exact
```

输出格式：`■ 资料X 书名　p页码` + 命中行（`>` 标记）+ 上下文。
资料3 会自动换算成「书页N (PDF pM)」，因为该书 PDF 页 = 书页 + 10。

## 四、补充 OCR

```bash
# 整本
python tools/ocr_pdf.py "<pdf路径>" ocr/资料1_低压供配电设备选型手册 --dpi 150 --workers 3

# 只处理某几段（推荐，速度快）
python tools/ocr_pdf.py "<pdf路径>" ocr/资料1 --dpi 150 --workers 3 --start 375 --end 604

# 合并成整本 md
python tools/merge_ocr.py 资料1
```

特性：断点续传（已存在的页自动跳过）、多进程、按坐标重排保留表格列。

**速度参考**：约 4.3 秒/页（150 dpi，3 进程）。8 进程反而更慢——onnxruntime 线程超订，别开太多。

## 五、OCR 能力说明（重要）

本机 OCR = **rapidocr 3.10 + onnxruntime（PP-OCRv6）**，纯 CPU。
实测效果：**能把字体映射损坏的数字救回来**。
例：资料1 p422 原文字层是 `’((`、`+3(`，OCR 得到 `500`、`160`，表格结构完整（型号 DW10-400/2、额定电流 100/150/200/400、热稳定性 12×10⁶、分断能力 15000）。

所以：**资料1、资料4 的数字，以 OCR 版为准，文字层版作废。**

## 六、使用纪律

1. 引用数字前先看来源。资料1、4 的**文字层版本数字不可用**，只能读 OCR 版或看原页。
2. 资料5 未处理，别引用。
3. 本库是**选型逻辑 + 参数查证**用，最终报价参数以厂家样本为准（ABB/施耐德/正泰官方选型手册）。
4. 覆盖度见 `00_知识边界与覆盖度.md`，🟡 和 ❌ 的项不要当已知用。

## 七、资料补齐（用户陆续提供）

国标、教材、论文按类型放入对应目录：

| 目录 | 放什么 | 命名建议 |
|---|---|---|
| `standards/` | 国标 GB / 行标 DL/T、JB/T | `GB-T 3906-2020 高压开关设备.pdf` |
| `books/` | 教材、设计手册 | `工厂供电 第6版 刘介才.pdf` |
| `papers/` | 论文、技术文章 | `2024 低压柜温升研究.pdf` |

**补齐流程**：

1. **先查版本**：`references/国标与教材清单.md` §一.3 —— 旧版（如 GB/T 7251.1-2013）只能作参考，**不能作为验收依据**
2. 文件放入对应目录
3. 在清单 §九「补齐进度登记」把状态 ⬜ 改为 ✅，填文件名
4. PDF 需检索时，用 `tools/ocr_pdf.py` 转文本，放 `txt/`
